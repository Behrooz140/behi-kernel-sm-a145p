🔥 behi Kernel - Samsung Galaxy A14 4G 🔥
📱 Device: Samsung Galaxy A14 4G (a14m / SM-A145P)
🧠 SoC: MediaTek Helio G80 (MT6769V)
🐧 Kernel: 6.6.92 GKI (android15-6.6)
🤖 Android Version: 15 (base A145PXXSDDZH1)
👤 Developer: @behi350
📅 Build Date: 2026/11/15 - v1.4

🌟 Boot-image-only release: nothing to install inside Android, no KernelSU modules, no vendor_dlkm changes. Flash boot and done.

🚀 What works:
• KernelSU v3.3.1 (version 32680) built into the kernel
• Droidspaces-ready container stack: PID / IPC / UTS / mount / user namespaces, cgroup v2, OverlayFS, FUSE, TUN/TAP, veth / bridge / macvlan
• Networking: CAKE qdisc (SQM / low latency), TTL/HL targets, xt_cpu, ipset
• Storage & network filesystems: SquashFS (XZ / LZ4 / ZSTD), NFSv4.2, SMB/CIFS
• All stock /vendor and /vendor_dlkm modules keep loading - exported symbol CRCs are verified against the known-good baseline on every build
• Stock CPU clocks (1.8 / 2.0 GHz) - no overclock, no voltage changes

🆕 What's new in v1.4:
• IPv6 NAT / masquerade support for Droidspaces --net=nat containers (CONFIG_IP6_NF_NAT + IP6_NF_TARGET_MASQUERADE)
• CI ABI gate now also rejects the cgroup options that would break stock vendor modules, so a bad kernel can never be released

⚠️ Bugs & Known Issues:
• Droidspaces --cpus (cgroup v2 cpu.max) and --pids-limit (pids.max) are still NOT supported. The needed cgroup controllers change exported GKI structures and break the stock vendor module ABI, so Droidspaces skips those two flags. Memory limit, swap limit and CPU usage accounting work fine.
• USB serial adapters need a separate module build: CONFIG_USB_SERIAL stays =m exactly like stock, and no .ko files are shipped.
• Only SM-A145P (a14m) is supported - NOT SM-A145F, SM-A145R, SM-A146B or SM-A146P/U.
• Report any other bugs in the support group!

📦 Installation:
1. Unlock your bootloader.
2. Flash A145P-Kernel-v1.4-Odin.tar.md5 in the AP slot via ODIN (Uncheck Auto-Reboot).
3. Reboot and verify: su -c 'uname -r' → 6.6.92-android15-8-abA145PXXSDDZH1-4k-behi-v1.4

↩️ Rollback: flash your previous working boot image, or the full stock A145PXXSDDZH1 firmware (HOME_CSC keeps your data).
